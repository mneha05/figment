# Experiment design

This is a reproducibility and review checklist for the Figment simulated Figgie-style market, not financial trading advice.

Define one hypothesis before modifying an agent. Record agent version, opponent mix, initial cash, deck seed, round count, and chosen metric. Compare paired rounds under identical deck seeds to reduce variance. Report confidence intervals rather than only mean profit.

## Evidence to retain
- Exact command and source commit
- Random seeds and scenario settings
- Raw outcomes and pass/fail assertions
- Known limitations and follow-up experiments
