# Agent ablation

This is a reproducibility and review checklist for the Figment simulated Figgie-style market, not financial trading advice.

Compare the market maker against versions without order-flow updates, inventory skew, and uncertainty-based spread changes. Change one element at a time. Use the same seeds and counterparties; attribute improvements only when repeatable under held-out games.

## Evidence to retain
- Exact command and source commit
- Random seeds and scenario settings
- Raw outcomes and pass/fail assertions
- Known limitations and follow-up experiments
